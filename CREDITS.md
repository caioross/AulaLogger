# Créditos

O AulaLogger é construído sobre ombros de gigantes da comunidade open source. Este arquivo lista as principais dependências e suas licenças.

## Modelos e bibliotecas de IA

### Transcrição

- **[Whisper](https://github.com/openai/whisper)** — modelo de transcrição (OpenAI) — MIT
- **[whisper.cpp](https://github.com/ggerganov/whisper.cpp)** — implementação C++ portável — MIT

### LLMs locais

- **[llama.cpp](https://github.com/ggerganov/llama.cpp)** — runtime para LLMs em C++ — MIT
- **[Gemma 2](https://huggingface.co/google/gemma-2-2b)** — modelo (Google) — Gemma Terms of Use
- **[Phi-3](https://huggingface.co/microsoft/phi-3)** — modelo (Microsoft) — MIT
- **[Llama 3.2](https://huggingface.co/meta-llama)** — modelo (Meta) — Llama Community License

### Diarização

- **[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)** — pipeline de speech models — Apache 2.0
- **[pyannote.audio](https://github.com/pyannote/pyannote-audio)** — modelos VAD/segmentação convertidos para ONNX — MIT

### Áudio

- **[RNNoise](https://github.com/xiph/rnnoise)** — denoise neural — BSD-3-Clause
- **[DeepFilterNet](https://github.com/Rikorose/DeepFilterNet)** — denoise avançado (opcional) — MIT/Apache-2.0
- **[Silero VAD](https://github.com/snakers4/silero-vad)** — voice activity detection — MIT
